## Story Naming Convention

All user stories follow the pattern: `DBXXX: <Story Name>`

- **DB** = DouroBats
- **XXX** = Sequential number (001, 002, etc.)

## Story Points Scale

We use Fibonacci sequence for estimation (mid/senior developer effort):
- **2 points** - Very small task (few hours - half day)
- **3 points** - Small task (half day - 1 day)
- **5 points** - Standard feature (1-2 days)
- **8 points** - Complex feature (2-4 days)
- **13 points** - Very complex, should be broken down further

## Organization

All stories are numbered sequentially (DBXXX). You can organize them on your project board into:
- **MVP** - Critical features for initial release
- **Ready** - Can be started now
- **Blocked** - Waiting on dependencies (e.g., backend APIs)
- **Future** - Nice to have, not urgent
